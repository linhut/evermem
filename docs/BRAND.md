# 恒忆 Evermem · 品牌视觉规范（BRAND）

> 制定：2026-10-01 · 适用范围：应用图标、界面、安装包、网页、文档、宣传物料。
> 资产目录：`brand/`（SVG 源、多尺寸 PNG、ICO/Favicon），渲染脚本 `scripts/render_logo.js`（PNG）、`scripts/make_logo_ico.py`（ICO）。

---

## 一、Logo 设计与寓意

主图形 = **三条经验弧 + 中心记忆晶核**：

- **三条弧**（每段 100°，留 20° 间隙）：来自不同会话/来源的经验，从三个方向注入；
  弧端点（金色圆点）是"经验注入点"，象征经验自动进库。
- **中心晶核**（圆角菱形，45° 与弧线错位）：跨会话复用的核心经验与记忆库本体。
- **底座细环**（低透明度）：记忆的承载底座——全本地、零云端，一切围绕核心运转。

一句话释义：**经验从四面八方来，沉淀成核心记忆，随会话恒久复用**（呼应"恒忆"）。

配色含义：蓝 = 理性沉淀；深蓝 = 纵深可靠（本地存储）；金 = 经验的珍贵价值。

## 二、标准色

| 角色 | 名称 | HEX | RGB | 说明 |
|---|---|---|---|---|
| 主色 | Evermem Blue | `#4A7DFF` | (74, 125, 255) | 主弧、细环、单色版用色 |
| 深色辅助 | Evermem Indigo | `#2B3E8F` | (43, 62, 143) | 第二条弧、渐变暗端、深底反白时文字 |
| 晶核渐变 | Core Gradient | `#6FA0FF → #2B4FD8` | (111,160,255)→(43,79,216) | 中心菱形填充（45° 对角） |
| 点缀色 | Experience Gold | `#FFB84D` | (255, 184, 77) | 三个注入点（仅彩色版使用） |
| 中性文字 | Ink | `#1F2430` | (31, 36, 48) | 字标/界面主文字 |
| 次级文字 | Slate | `#7A8299` | (122, 130, 153) | 字标副标题/界面辅助文字 |

使用规则：
- 彩色版至少同时出现「主色蓝 + 金」才算完整品牌色；仅单色场景用单色版，不要用细节压缩的彩色版。
- **不允许**：改变色值、反相主色、给金色注入点换色、在彩色背景上直接叠彩色版（用白色版或加深底）。

## 三、安全边距与最小尺寸

- **安全边距**：Logo 四周留白 ≥ 图形宽度(W) 的 **25%**（等距）。示例：图标宽 100px 时四周 ≥ 25px。
- **最小尺寸**：
  - 彩色版：应用/网页图标 ≥ 24px；文档插图 ≥ 40px。
  - 单色版：可小至 16px（水印、角标）。
  - 小于最小尺寸时**不要缩小彩色版**，改用单色版或简化版（仅晶核 + 一条弧）。
- 图标容器：应用图标建议圆角矩形（约 22.4% 圆角比例），Logo 占容器 82%~86%。

## 四、单色版

- 文件：`brand/evermem-logo-mono.svg`（全 `#4A7DFF`）。
- 适用：灰度印刷、单色水印、≤24px 角标、表单区、彩色不允许的场合。
- 深底反白版：把「单色版」整体换为白色（`#FFFFFF`），透明度规则不变（细环 0.18→0.3 补偿）。

## 五、字体推荐

| 场景 | 字体 | 回退 |
|---|---|---|
| 英文/数字（字标 EVERMEM） | Inter / Manrope（无衬线） | `sans-serif` |
| 中文（恒忆） | 思源黑体 Source Han Sans / 苹方 / 微软雅黑 | `'Noto Sans SC', sans-serif` |
| 界面 UI | 与中文字体同族，权重 400/500/600 | 一致 |

字标组合版 `brand/evermem-logo-full.svg` 已内置字体家族声明；导出 PNG 需渲染端装有以上字体，
缺字体时回退系统默认 sans-serif（形状不受影响，仅字形变化）。

## 六、界面使用规范

| 位置 | 文件 | 尺寸建议 |
|---|---|---|
| 应用主图标（Windows exe/安装包） | `brand/evermem.ico`（6 尺寸内嵌） | 最大 256px 帧 |
| Favicon（网页/桌面 Web） | `brand/favicon.ico` + `brand/favicon.png` | ICO 16+32；PNG 32 |
| 标题栏/关于页 | `brand/png/evermem-logo-{32,64}.png` | 32px 标题栏；64px 关于页 |
| 启动页/加载屏 | `brand/png/evermem-logo-128.png`（或 256） | ≥128px，深底可配白字 |
| 系统托盘 | `brand/png/evermem-logo-16.png` | 16px（建议用单色版渲染的小图，清晰） |
| 文档/网页页眉 | `brand/evermem-logo-full.svg` | 高度 24~48px 文字部分保持可读 |

背景方案：
- **浅色界面**：彩色版直接使用（透明底）。
- **深色界面/深色托盘**：使用反白版（见四）或彩色版 + 半透明白色底圆角容器。
- 不要在纯金、纯红、低对比度纹理上使用主 Logo。

## 七、文件清单

| 文件 | 用途 |
|---|---|
| `brand/evermem-logo.svg` | 彩色主版（透明底，矢量源，唯一事实源） |

## 八、禁止事项

- 拉伸变形、旋转 90°/45° 之外的角度、裁剪任意一条弧。
- 更换颜色、调整弧长/间隙比例、删除注入点。
- 在 Logo 上叠文字/阴影/渐变遮罩。
- 把彩色版缩小到 24px 以下直接使用（用单色/简化版）。
