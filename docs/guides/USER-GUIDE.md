# 恒忆 Evermem · 零基础使用说明

> 这份文档写给**完全不懂编程、电脑里没有 Python、也没装过任何开发环境**的人。
> 你只需要会：下载文件、双击、复制粘贴路径。一步一步照做即可。

---

## 0. 先搞清楚三件事

**① 恒忆是什么？**
一个装在**你自己电脑上**的「记忆/知识库」工具。你平时积累的经验、方案、踩坑记录，可以存进去，以后要用的时候搜一下就出来。

**② 需要联网吗？——日常使用完全不需要。**
所有数据都存在你自己的硬盘里，不上传任何服务器。
只有在你主动开启「云备份」（阿里云 OSS / 腾讯云 COS / 百度网盘等）时才会联网，不开就一次都不连。

**③ 我的数据存在哪？**
默认存在**你放置恒忆程序的那个文件夹**里。所以：

- ✅ 推荐：先建一个固定文件夹（例如 `D:\Evermem`），把程序放进去
- ❌ 不推荐：直接放在「下载」文件夹、桌面、`C:\Program Files` 里
  （下载文件夹容易被清理；`Program Files` 需要管理员权限，可能写不进去）

## 1. 下载

### 1.1 下载地址

👉 **https://github.com/linhut/evermem/releases/latest**

打开上面这个网址，页面往下拉到 **Assets（附件）** 区域，按你的电脑系统下载对应那一个文件即可。

### 1.2 该下载哪一个？

每个系统都有**绿色版**（解压即用）和**安装版**两种，按你的习惯选一个就行：

| 你的电脑系统 | 下载这个文件名 | 大概体积 | 说明 |
|---|---|---|---|
| **Windows**（Win10/Win11） | `Evermem-windows-v*-portable.zip` | 约 211 MB | **推荐**：解压后双击里面的 `Evermem.exe`，免安装 |
| **Windows**（Win10/Win11） | `Evermem-setup-v*.exe` | 约 142 MB | 双击按向导安装，自动建开始菜单、可选开机自启 |
| **macOS**（苹果电脑） | `Evermem-macos-v*.app.zip` | 约 178 MB | **推荐**：解压出 `Evermem.app` 后双击 |
| **macOS**（苹果电脑） | `Evermem-macos-v*.dmg` | 约 220 MB | 打开后把 `Evermem.app` 拖进「应用程序」 |
| **Linux** | `Evermem-linux-v*-portable.tar.gz` | 约 231 MB | 解压后进入 `Evermem/` 目录，`chmod +x Evermem` 再运行 |
| **Linux** | `Evermem-linux-v*.deb` | 约 177 MB | Debian / Ubuntu 系安装包 |

> 文件名里的 `*` 是版本号，比如 `v0.2.11`，**选数字最大（最新）的那个**。
> 拿不定主意就选带 `portable` 的绿色版：不写注册表、卸载直接删文件夹、数据也存在同目录。

### 1.3 下载很慢 / 打不开 GitHub？

GitHub 在国内访问有时不稳定，可以：

1. 换时间段重试，或用手机热点试试；
2. 让朋友下载后通过微信/QQ/网盘传给你（**注意**：下面第 1.4 步的校验一定要做）；
3. 关注项目发布页是否提供了国内镜像（如网盘分流链接）。

### 1.4 （建议做）下载后校验一下文件完整不完整

文件很大，下载中断会产生一个打不开的残次品。

- **Windows**：在文件所在文件夹按住 `Shift` + 右键 →「在此处打开 PowerShell 窗口」，输入：

  ```
  certutil -hashfile Evermem-windows-v0.2.11-portable.zip SHA256
  ```

- **macOS**：终端里输入 `shasum -a 256 文件名`
- **Linux**：终端里输入 `sha256sum 文件名`

把算出来的一长串字符，和发布页里附带的 `SHA256SUMS.txt` 对照。**完全一致**才说明没下坏。
（如果发布页暂时没有提供 `SHA256SUMS.txt`，可以跳过这一步。）

## 2. 安装与启动

### 2.1 Windows 用户（Win10 / Win11）

**第 1 步：建一个文件夹**
打开「此电脑」→ 进入 D 盘（没有 D 盘就用 C 盘）→ 新建文件夹，命名为 `Evermem`。
最终路径类似：`D:\Evermem`

**第 2 步：把下载的文件放进去**

- 下载的是**绿色版** `Evermem-windows-v*-portable.zip`：右键 →「全部解压缩」，得到 `Evermem` 文件夹，把整个文件夹移到 D 盘根目录，最终路径是 `D:\Evermem\Evermem.exe`。
- 下载的是**安装版** `Evermem-setup-v*.exe`：双击运行，安装向导里把「目标目录」填成 `D:\Evermem`，装完直接跳到第 4 步。

> 绿色版里的可执行文件本来就叫 `Evermem.exe`，不需要改名。以后升级请覆盖到同一目录，这样开机自启才不会失效。

**第 3 步：双击运行**
双击 `D:\Evermem\Evermem.exe`。

**第 4 步：（常见）如果弹出蓝色警告框**
 Windows 会显示：

> **Windows 已保护你的电脑**
> Microsoft Defender SmartScreen 阻止了无法识别的应用启动。

这是因为程序还没有购买商业代码签名证书（个人开源项目的常见情况），**不是病毒**。
处理方式：点击 **「更多信息」** → 再点 **「仍要运行」**。

> 如果杀毒软件（360 / 火绒 / 电脑管家）弹窗拦截，选择「允许运行」或「加入白名单/信任区」。
> 详细解释见第 5 节。

**第 5 步：耐心等 10～30 秒**
第一次启动会比较慢（程序要解压自带的浏览器内核，约几百 MB），**这段时间看起来像"没反应"，请耐心等**。
正常现象：任务管理器里能看到 `Evermem.exe` 在跑，CPU 或磁盘在动。
机械硬盘可能要等 40 秒以上。

**第 6 步：看到界面**
窗口打开后就是恒忆主界面了。右下角**系统托盘**（时钟旁边）会出现恒忆图标。

> **关闭窗口 ≠ 退出程序**：点右上角 `×` 时，程序会最小化到托盘继续运行（这样你随时能搜索）。
> 想彻底退出：右键托盘图标 → 退出。

---

### 2.2 macOS 用户（苹果电脑）

**第 1 步：解压**
双击下载的 `Evermem-macos-v*.app.zip`，得到 `Evermem.app`。

**第 2 步：拖到「应用程序」**
把 `Evermem.app` 拖进「应用程序」文件夹（也可以放在你自己的文件夹里，比如 `文稿/Evermem`）。

**第 3 步：双击打开 —— 如果被拦截**
因为程序还没做苹果官方签名公证，可能出现下面两种提示之一：

- 「**Evermem.app 已损坏，无法打开。您应该将它移到废纸篓。**」
- 「**无法打开"Evermem"，因为它来自身份不明的开发者。**」

处理办法（任选其一）：

**办法 A（推荐，一次搞定）**
1. 打开「系统设置」→「隐私与安全性」；
2. 往下拉，找到提示「已阻止使用 Evermem，因为来自身份不明的开发者」；
3. 点右边的 **「仍要打开」** → 输入开机密码确认 → 点「打开」。

**办法 B（终端命令，去掉隔离标记）**
打开「终端」（Launchpad → 其他 → 终端），粘贴下面这行后回车（把路径换成你的实际位置）：

```bash
xattr -dr com.apple.quarantine /Applications/Evermem.app
```

然后重新双击即可。

**第 4 步：首次启动较慢**
同上，浏览器内核较大，第一次可能要等 10～30 秒。

---

### 2.3 Linux 用户

**第 1 步：解压（绿色版）**
下载的是 `Evermem-linux-v*-portable.tar.gz` 时，在文件所在目录打开终端：

```bash
tar -xzf Evermem-linux-v0.2.11-portable.tar.gz
cd Evermem
```

（文件名按你实际下载的版本号改）

> 下载的是安装版 `Evermem-linux-v*.deb` 的话，`sudo dpkg -i Evermem-linux-v0.2.11.deb` 装完直接跳到第 3 步，应用菜单里会出现恒忆。

**第 2 步：加执行权限并运行**
浏览器下载下来的文件**默认没有执行权限**，双击会没反应或者被当成文本打开：

```bash
chmod +x Evermem
./Evermem
```

也可以在文件管理器里右键 →「属性」→「权限」→ 勾选「允许作为程序执行」，之后就能双击了。

**第 3 步：如果报"缺少 .so 库"**
例如：

```
error while loading shared libraries: libxcb-cursor.so.0
```

说明系统缺 Qt 运行库，按你的发行版装一下：

- **Ubuntu / Debian**：
  ```bash
  sudo apt update
  sudo apt install -y libgl1 libegl1 libxkbcommon0 libdbus-1-3 libfontconfig1 \
      libxcb-cursor0 libxcb-xinerama0 libxrandr2 libxfixes3 libxcb-icccm4 \
      libxcb-keysyms1 libxcb-shape0
  ```
- **Fedora / RHEL**：`sudo dnf install -y mesa-libGL mesa-libEGL dbus-libs libxcb libXrandr libXfixes fontconfig`
- **Arch**：`sudo pacman -S --needed qt6-base qt6-webengine`

## 3. 首次运行要做的一件事：设置数据位置

### 3.1 为什么要设置

程序默认把数据放在**它自己所在的文件夹**。如果你希望数据和程序分开（推荐），请手动指定一次。

### 3.2 操作步骤

1. 打开恒忆，左侧点 **「系统」→「数据与维护」**；
2. 找到 **「① 数据位置（可自由选择）」**；
3. 三个输入框分别填：
   - **记忆库**：建议 `D:\EvermemData`（macOS/Linux 用 `/Users/你的名字/EvermemData` 或 `/home/你的名字/EvermemData`）
   - **块库**：建议 `D:\EvermemData\chunks`
   - **扫描根**：填你平时放资料的上级目录，例如 `D:\`
4. 填完点 **「保存」**；页面会显示权限与剩余空间检查结果，全绿才算成功；
5. **完全退出程序并重新启动**（这一步不能省，改完要重启才生效）。

### 3.3 开机自启动（可选）

**系统 → 接入设置 → ③ 开机启动 →「开机自启动」开关**，打开后登录系统就自动在托盘运行。

> 注意：开关状态是从系统真实自启项读出来的。如果你之后**改了程序文件名或移动了位置**，自启动会失效，需要重新关一次再开一次。
> 如果你是用浏览器打开恒忆（不是桌面壳），这个开关是灰的、不可点，属于正常现象。

## 4. 日常怎么用（30 秒上手）

- **搜东西**：左上角搜索框输入关键词，比如 `融合通信`、`公文`、`搬迁`
- **存经验**：右上角「＋ 新建」→ 选类型（经验 / 配方 / 事实）→ 写标题和正文 → 保存
- **备份**：左侧「数据备份」，先做**本地备份**（零配置），想更保险再配云盘
- **深色模式**：左下角切换
- **开发者工具**：按 `F12`

## 5. 常见问题排查

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| **双击后完全没反应，窗口不出来** | ① 首次启动解压慢 ② 程序已经在运行了 | ① 等 30 秒，看任务管理器有没有进程 ② 看右下角托盘，已经有一个在跑了 |
| **又双击一次还是没反应** | 单实例保护：第二个进程会自动退出 | 去托盘找图标；没有就重启电脑再试 |
| **SmartScreen 蓝色警告** | 程序未做商业代码签名 | 点「更多信息」→「仍要运行」 |
| **杀毒软件报毒 / 自动删除** | PyInstaller 打包 + 内嵌浏览器内核是误报高发组合 | 加入白名单/信任区；到发布页核对 SHA256 确认文件没被篡改；用 VirusTotal 复检 |
| **提示"无法分配空闲端口"** | 端口被占用或防火墙拦截本地回环 | 关闭可能冲突的软件，重启后再试 |
| **窗口打开但是一片白** | 显卡驱动/远程桌面环境下浏览器内核无法渲染 | 程序已默认软件渲染；仍白屏就重启一次；虚拟机建议分配 4GB 以上内存 |
| **提示"无法写入"/"权限不足"** | 程序放在了 `C:\Program Files` 等受保护目录 | 挪到 `D:\Evermem` 这类普通文件夹 |
| **换了个文件夹后，以前的数据不见了** | 数据默认跟着程序目录走 | 回到旧目录把 `pmem_config.json`、`notes/`、`index.json` 等复制到新目录；或在新目录的「数据位置」里指回旧数据目录 |
| **macOS 提示"已损坏"** | 未签名公证 | 见 2.2 第 3 步 |
| **Linux 双击没反应** | 缺执行权限 | `chmod +x 文件名` |
| **Linux 报缺 .so** | 缺 Qt 系统库 | 见 2.3 第 3 步 |

## 6. 怎么更新到新版本

1. 到发布页下载新版本的文件；
2. **先退出正在运行的恒忆**（托盘图标右键 → 退出）；
3. 把新文件**覆盖**到同一个位置、**用同一个文件名**（这也是建议改名成 `Evermem.exe` 的原因）；
4. 双击启动即可，**数据不会丢**（数据在 `EvermemData` 或程序目录里，不在 exe 里面）；
5. 如果之前开了开机自启动，更新后建议去「⑦ 桌面常驻」关一次再开一次。

> 稳妥做法：更新前用「数据备份」做一次本地备份。

## 7. 卸载与数据保留

- **卸载程序**：Windows 直接删掉那个 exe（便携版没有注册表残留）；macOS 把 `.app` 拖到废纸篓；Linux 删掉那个文件。
- **卸载不会删你的数据**：数据在你设置的「数据位置」目录里，删程序不影响。
- **想彻底清空数据**：手动删除数据目录（例如 `D:\EvermemData`）。**删之前务必先备份。**

## 8. 遇到问题怎么反馈

反馈时请附上这四样，能大幅提升解决速度：

1. 你的**系统版本**（如 Windows 11 23H2 / macOS 14.5 / Ubuntu 22.04）
2. 恒忆的**版本号**（发布页文件名里的 `v0.2.3` 之类）
3. **具体报错文字**或截图
4. 你做了什么操作之后出现的（例如"双击后"、"点了保存之后"）

反馈渠道：

- **GitHub Issues（推荐，问题可追踪）**：https://github.com/linhut/evermem/issues
- **项目主页**：https://www.linhut.cn
