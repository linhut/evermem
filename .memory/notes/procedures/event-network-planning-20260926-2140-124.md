从运动会网络规划拓扑图（Visio，12 页、4000+ 图形元素）的架构分析提炼。大型赛事网络规划用"图纸集"而非单张图。

## 图纸组织：总—分—专项三层

1. **全景页**：整体网络拓扑——三张业务专网合一的总体结构（竞赛专网 / 互联网 / 转播专网）
2. **分网拓扑页**：三张专网各自的端到端拓扑（一网一页，画清全链路）
3. **场馆模板页**：单场馆内部的标准组网模板（竞赛专网 / 互联网 / 转播专网各一张）——**重复用于全部场馆**，不必每馆单独画
4. **分工界面页**：竞赛专网 / 互联网 / WiFi 网的分工界面，标注筹委会与场馆的责任边界

## 经验要点

- **模板复用**：单场馆组网抽象成标准模板，几十个场馆套用同一模板，避免重复劳动与口径不一致
- **一网一页**：三张专网各自成页，避免一张总图画到不可读
- **分工界面独立成页**：网络建设的责任边界（筹委会 vs 场馆方）单独标注，防止扯皮
- 图纸带版本日期（如 20260610），配套一份架构分析报告说明组织逻辑

## 例外与边界

- 场馆特殊性（个别大型场馆）需要在模板基础上加注差异
- 涉及的具体 IP、设备型号不入笔记
