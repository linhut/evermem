从广电总局项目授权函与厂家授权材料清单提炼。政企/政府采购项目中法定代表人授权委托书与授权材料收集的要点。

## 法定代表人授权委托书（领取中标通知书场景）

致：招标代理机构（如 XX 省招标有限责任公司）
- 法定代表人的姓名、职务
- 委托本司员工 + 身份证号，到贵单位接洽领取 XX 项目（**项目名称、政府采购编号、委托代理编号三号齐列**）中标通知书
- 委托期限（起止日期）
- **代理人无转委托权**
- 授权函于 X 年 X 月 X 日签字生效
- 投标人名称（公章）、法定代表人及联系电话、委托代理人及联系电话、日期
- 附：委托代理人身份证扫描件

## 授权材料收集要点

- 需厂家授权明细表：逐家登记厂家（投标人）名称、地址等工商信息，便于核查与归档
- 厂家设备清单与材料收集：设备类项目投标须同步收集各厂商的授权书、产品检测报告、代理资质等支撑材料，避免开标时缺授权被废标

## 复用要点

- 授权函三要素必须写全：**项目三号（名称/采购编号/代理编号）+ 委托期限 + 无转委托权**；缺编号代理机构无法对应项目，缺"无转委托"条款易被质疑
- 领取中标通知书、投标、合同签署三个场景各备一份授权模板，仅改委托事项与期限
- 授权材料按项目归档（厂家明细表 + 授权书原件/扫描件），后续履约、验收也要用

## 例外与边界

- 涉密项目、联合体投标的授权规则不同，以招标文件要求为准
- 文中身份证号、电话等个人信息不写入笔记正文（本文已隐去）
