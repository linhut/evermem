从云网通信组座谈会发言稿提炼。与"场馆信息化勘察要点"（id 20260926-2110-120）互补——本条聚焦网络通信侧。

## 云网通信组工作范围（三大领域）

依据《筹委会信息技术部工作方案》：云资源池、基础网络、公共通信保障。

## 场馆网络勘察要点（检查清单）

- 竞赛专网、互联网、场馆内综合布线现状
- 成绩传输、计时记分、仲裁视频等专用设备：拟安装位置、**供电、网络接口条件**
- 室内外补盲 AP：安装位置（墙面/吊顶/立杆）、供电条件、信号覆盖预估
- 临时光纤/网线：敷设路由、桥架利用情况
- 光纤及桥架（双方协同）：利旧光纤剩余芯数、通断测试；新放光纤路由与用量估算；桥架空间利用率
- 露天场馆特殊要求：防雷覆盖、设备防雨防尘、室外线缆铺设路径与固定方式

## 公共通信专项（运营商负责、场馆方配合）

1. 4G/5G 信号覆盖测试（记录弱覆盖/盲区点位）
2. 主干光缆路由及**双路由保护**确认
3. 容量需求评估（按预计人流量）
4. 应急通信车停放点位（预留场地、供电、传输接口）
5. 场馆通信设备供电方案及备用电源需求

## 分工界面（三方法定责）

| 工作 | 负责方 | 说明 |
|---|---|---|
| 固定综合布线基础设施（桥架/管/底盒/墙插） | 场馆方 | 永久设施，需确保完好 |
| 固定布线改造或补充 | 场馆方 | 按信息技术部需求清单实施 |
| 场馆内临时布线（功能房点位至终端、补盲 AP、临时光纤、临时机柜） | 筹委会信息技术部 | 设计及施工 |
| 成绩传输/计时记分/仲裁视频等专用设施设备 | 筹委会信息技术部 | 提供、部署、连接布线 |
| 竞赛专网/互联网核心网络设备 | 筹委会信息技术部 | 设备由我部提供 |
| 场馆现有网络设备（利旧可用） | 双方协商 | 提供品牌型号版本、评估兼容性 |
| 公共通信（4G/5G、应急通信车） | 省通信管理局（运营商） | 场馆方配合 |

## 经验要点

- **供电和接口条件是场馆侧最大变量**：专用设备点位要逐个核实电源与网络口
- 利旧决不是免费午餐：必须做纤芯数实测、通断测试、兼容性评估，不测不能用
- 分工界面按"永久设施归场馆、临时部署归我部、公共通信归运营商"三原则划分，写成表格落定
- 座谈会发言稿是"勘察汇报 + 分工确认 + 需求对接"三合一文档，结构值得复用（范围-分工-需支持事项-下一步计划）

## 例外与边界

- 涉及的具体点位、人员名单不入笔记
- 其他场馆/赛事的公共通信配置（4G/5G）以当地运营商能力为准
