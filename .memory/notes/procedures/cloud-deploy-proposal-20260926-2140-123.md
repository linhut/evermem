信息技术部"系统上云部署方案"模板归纳（天翼云）。任何系统上云可套用此结构。

## 方案章节结构

1. 方案简介 → 上云目标 → 上云范围 → 部署策略（本次采用全新部署：云平台按生产标准构建完整运行环境，测试验收后上线）
2. 信息系统介绍：基本情况（名称/简称/类型/服务对象/用户规模/系统等级/数据类型/数据量级）、系统架构、网络架构
3. 资源申请明细：计算资源清单（实例名称/规格/数量/操作系统/用途）
4. 网络及安全规划：网络策略、VPC 与子网规划（创建专用 VPC…）
5. 实施计划（按步：申请资源 → 资源下发 → 网络和安全配置 → 测试验收 → 上线）
6. 评审记录（项目经理终审：通过/驳回/修改后重审）

## 上云目标四要素（写作模板）

- 规范化部署与上线运行
- 充分利用云平台弹性伸缩与高可用能力，保障业务持续稳定
- 统一安全防护体系，满足等保合规要求
- 降低基础设施运维复杂度，提升资源利用率

## 网络策略表格式（关键）

表格列：源 / 目的 / 端口 / 协议 / 动作 / 说明。典型分区：
- 竞赛专网区：场馆设备 → 云主机（如 19000 端口）
- 互联网区：公网地址 → 云主机
- 云内互访：云主机间直连
按"业务分区 + 端口级策略"描述，验收时逐条核销。

## 实施职责分工

- 信息系统管理组：提需求、验收
- 云网通信组：资源下发、网络配置
- 责任人 + 协助人两列，每步带计划时间

## 例外与边界

- 资源规格、IP、端口是示例占位，按实际填写
- 不同云平台（天翼云/政务云）网络能力有差异，VPC 与安全组配置需对应当前平台
