从 gongwen-skill 生成"工作提示函"与用户手动调整版的 OOXML 逐项对比报告中提炼。任何 AI 生成的公文定稿前，按这份清单验收。

## 检查方法

按维度逐项提取 OOXML 属性比对（skill 版 vs 人工定稿版）：
分节与页面设置 → 页眉页脚与页码 → 段落样式与格式 → 表格（列宽/边框/合并/单元格格式）→ 结构（正文/落款/附件/联系人）。

## 质量清单（发现过的问题，按严重度）

**表格（最常见短板）**
- T1 列宽均分：长内容列（60 字）挤在 2.6cm 列宽里，每格 5~8 行，22 行附表撑成数十行——**应按内容分配列宽**
- T2 表格默认虚线边框：公文附表应用实线（single）
- T3 宽表放纵向页：6 列挤 15.5cm 版心换行严重——宽表应自动引导放横向分节（landscape）

**样式**
- S1 全文 Normal 样式，缺正文样式层级
- S2 落款单位与日期不分行
- S3 附件页标题单行显示

**页码**
- P1 单节不支持横向附表
- P2 页码是字面文本而非域（应统一用 PAGE 域）
- P3 节间页码不连续

**结构**
- C1 缺"此页无正文"占位（公文规范）
- C2 联系人括注位置（如"（联系人：XXX，电话：XXX）"）不规范
- C3/C4 落款与日期排版（右对齐、空格、居中位置）

## 验收顺序建议

1. check 级别项（P0）先清零
2. 再按 结构 → 样式 → 表格 → 页码 顺序检查"成品感"维度
3. 长文表格优先看列宽与分节，这是最大的观感扣分项

## 对 gongwen-skill 的改进建议（已沉淀在报告里）

- 用 style-learn 学习本单位定稿排版样式生成自定义模板
- 宽表自动转横向分节；表格默认实线边框 + 按内容分配列宽
- 页码统一用域；落款支持分行
- 这几点可作为 skill 后续迭代的需求清单

## 例外与边界

- 不同单位格式要求有差异（如联系人括注位置），以本单位定稿样式为准
- 涉密公文按内部规定执行，本清单只覆盖排版不覆盖保密审查
