从长沙市政府投资信息化建设项目可研编制模板（市数据局口径）提炼。与笔记 139（华信实例）互补：139 是成品实例，本篇是**官方模板骨架**，按此骨架配肉即可。

## 封面与前置页（常被忽略但评审必查）

- 项目名称 / 项目类型 / **建设单位（盖章）** / 责任人 / 日期
- 编写单位 / **资质证书**（发证机关/等级/编号）——可研编制单位要有相应资质
- 法定代表人 / 技术负责人 / 项目负责人
- **编制人员名单**：编制、校核、审核、审定、批准（五级签审链）

## 章节骨架（模板目录）

1. 项目简介：名称、建设单位及负责人/项目责任人、编制单位、编制依据、建设目标/规模/内容/建设期、总投资及资金来源、经济与社会效益、主要结论和建议
2. 项目建设单位概况：建设单位与职能、实施机构与职责
3. 需求分析及项目建设必要性：
   - 项目提出背景和依据 / 现状分析 / 政务目标分析
   - **业务需求 / 功能需求 / 安全防护需求 / 数据资源需求 / 信息量分析预测及性能需求 / 基础资源需求**（六类需求分列）
   - 项目建设的意义和必要性
4. 总体建设方案：建设原则策略 / 总体目标与分期目标 / 总体任务与分期内容 / 总体设计方案 / 总体技术路线 / 关键技术分析
5. 本期项目建设方案：建设目标规模内容 / 标准规范建设内容 / 总体架构设计 / 数据库建设方案 / 应用支撑平台和应用系统建设方案 / **场所智能化系统建设方案**

## 场所智能化系统设计（指挥中心类项目细节）

- 智能化系统清单：大屏显示 / 会议发言 / 音响扩声 / 分布式中控 / 视频会议 / 集中控制六大系统 + 品牌定位（一线品牌、稳定耐用、低返修）
- **LED 屏选型硬规则**：最近视距 = 点间距 × 1000；最佳视距 = 点间距 × 3000（先测领导席/最近座位距离反推点间距）；实例：发现处置区 P≤0.94、迎宾区 P≤1.25、环形屏 P≤3
- 系统组成三子系统：显示子系统 / 信号源子系统 / 控制子系统（+配电子系统、通讯传输）

## 复用要点

- 封面五级签审链和资质证书页是市级评审的硬门槛，缺了直接退件
- 六类需求分列（业务/功能/安全/数据/性能/基础资源）是模板特色，比老套路（现状→需求→必要性）更规范——评审委员按此逐项打分
- 场所智能化章节要明确范围边界（"土建/配电/装修/暖通/消防不属于本设计"），避免被挑刺

## 例外与边界

- 此模板为长沙市口径，其他地市以当地数据局模板为准
- LED 选型公式是工程经验值，正式设计以厂家校核为准
