从筹委会信息技术部对张家界执委会信息技术部"信息系统使用事宜"复函提炼。平级单位之间就具体事项往来的"复函"写法（答覆类）。

## 复函结构（六段式）

1. 标题：关于 XX 事宜的函（或"关于 XX 的复函"）
2. 受文对象：XX 部门：（平级单位用部门名+冒号）
3. **复述来函要点**：贵单位报送的 XX 已收悉。其中提及"……"事宜。——原文引用对方关键诉求，表明认真研读
4. 处理经过 + 研判结论：XX 高度重视，第一时间对相关情况进行梳理研究。经研判（列出对比维度），结论是……
   - 对比维度写法（拒绝类复函的关键）：**赛事规模、项目设置、数据统计口径、功能适配标准、业务流程要求**等方面存在明显差异 → 对方诉求无法满足
5. 明确答复 + 建议：请贵单位结合 XX 实际，自主规划推进……，切实规避重复投入。感谢理解与支持。
6. 收尾："专此致函。" + 落款（机构全称/日期）+（联系人：姓名，电话）

## 关键写作经验

- 复函的"研判"部分要**给理由不给情绪**：用客观差异（口径/标准/流程）支撑结论，不用"由于我方原因"式表述
- 先复述后反驳：原文引用对方提法（加引号），再逐点对照说明差异，逻辑上无懈可击
- "专此致函"是函件专用收尾语，普通通知不用
- 平级公文用"函"不用"通知"，语气尊重（贵单位/请/感谢理解支持）

## 例外与边界

- 对上级用"报告/请示"，对平级用"函"，对下级用"通知/批复"——文种别用错
- 拒绝类复函要留台阶：结尾补一句建设性建议（本函即建议对方自行规划、规避重复投入）
