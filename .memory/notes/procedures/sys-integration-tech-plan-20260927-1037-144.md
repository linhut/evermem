从市政府综合指挥中心二期项目技术实施方案（中国电信承建方编制）提炼。与甲方侧方案（笔记 117/119/123）互补：甲方写"建什么"，承建方写"怎么建、用什么设备、怎么施工"。

## 章节结构（承建方实施方案）

1. 文档管理：修改记录（版本/日期/修改人/说明）/ 分发记录 / 审核者——承建方文档必须带版本控制，验收评审会看
2. 前言：编写目的 / 适用范围 / **完成标准**
3. 现状及需求分析
4. 总体设计：设计原则 / 技术路线（实例：微服务架构、前后端分离、组件化开发、分布式技术）→ 系统连接拓扑图 → 方案功能设计简介 → 可视化操作、所见即所得 → 集中控制 → 主要核心产品简介
5. 分系统实施方案（逐系统写）：设计指标 → 设计相关事项 → **设备选型原则** → 系统设计说明 → 实施细节（实例：会议室扩声系统含**建声装修建议**）

## 与甲方方案的关键差异（写作要点）

- 甲方初设/可研写"需求、目标、建设内容、投资"；承建方实施方案写"怎么落地"：拓扑、设备选型、施工设计、联调、验收
- 承建方方案要有**完成标准**（验收口径）——写清楚"做到什么程度算完成"，避免验收扯皮
- 逐系统展开时按"设计指标→设备选型→设计说明→实施细节"固定套路，评审容易过
- 设备选型原则单独成节（稳定性、利旧、国产化等），为采购清单提供依据
- 建声装修、综合布线这类"隐蔽工程"细节要写进方案，施工期争议多出在这里

## 例外与边界

- 本文档为传统音视频系统集成项目；纯软件项目（上云部署）参考笔记 123
- 承建方方案含商业机密（选型/报价逻辑），对外只交评审版
