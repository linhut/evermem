从"五级联动视频会议系统密码应用方案"（三未信安编制）提炼。政务信息系统走密评（密码应用安全性评估）时按此结构编制。

## 政策依据链（写作背景段必引）

- 《中华人民共和国密码法》：2020-01-01 实施
- 《国家政务信息化项目建设管理办法》（国办 2019 年底印发）：不符合密码应用和网络安全要求的不安排运行维护经费；建设单位应**同步规划、同步建设、同步运行密码保障系统并定期评估**（三同步）
- 公安部等保/关保指导意见：三级以上网络应正确、有效采用密码技术，在等保测评中同步开展密评
- **GB/T 39786-2021《信息安全技术 信息系统密码应用基本要求》**：2021-10-01 实施，密评基础性标准

## 章节结构（密评方案标准骨架）

1. 背景（政策驱动论证）
2. 系统概述：基本情况 / 网络拓扑 / 承载业务 / 软硬件构成（网络/安全/服务器存储/终端/密码产品）/ 关键用户及数据 / 管理制度
3. 密码应用需求分析：按**物理和环境安全、网络和通信安全、设备和计算安全、应用和数据安全、安全管理**五个层面（与等保 2.0 一一对应），每层列通用要求+风险控制需求
4. 设计目标及建设原则（原则+建设依据）
5. 技术方案：密码应用技术框架 → 五层面逐一"设计原理+密码服务流程" → 密钥管理设计（密钥结构体系/生命周期安全管理/管理规定与监督检查）→ 密码应用部署
6. 安全管理方案：制度（《商用密码安全管理制度》《密钥管理制度》）/ 人员（《商用密码人员管理制度》）/ 《密码安全操作规范》/ 实施 / 应急（事件分级/处置组织/响应机制/流程/公告/损失评估/预案激活条件）
7. 安全合规性分析
8. 实施保障方案：项目组织/实施内容/实施计划/培训/保障措施（组织、人员、监督检查、经费、质量）
9. 产品经费概算：密码设备清单

## 实施流程（密评闭环，关键经验）

编制方案 → 委托密评机构评估 → 评估通过后向密码管理部门**备案** → 密码应用改造 → 密评通过后上线 → **每年一次**密评评估并整改；运行中发现重大密码应用安全隐患须停运整改、重新评估后上线。

## 密码产品选型

选用通过检测认证的商用密码产品：服务器密码机、签名验签服务器、SSL VPN 安全网关、USB Key（数字证书私钥存储）等。

## 密码安全事件分级（应急章节模板）

特别重大（一级）/重大（二级）/较大（三级）/一般（四级）；参考判定线：密码相关终端与应用服务中断运行 **24 小时以上**、涉密信息广泛传播、核心安全配置失效等。

## 例外与边界

- 密评对象是政务系统（非涉密国密系统另有《商用密码管理条例》路径），涉密系统不适用
- 五层面框架与等保测评术语对齐，编制时须逐层引用系统实际设备与现状，不能照抄模板
