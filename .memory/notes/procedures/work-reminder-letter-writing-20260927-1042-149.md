从筹委会信息技术部对张家界执委会的"工作提示函"（写实版/稿版）提炼。上级部门推动下级(或平级单位)限期整改问题时的标准公文写法。

## 结构模板（五段式）

1. **受文对象**：XX 单位：（注意用冒号收尾）
2. **背景与定性**：近期开展 XX 检查/勘察，覆盖范围 → 总体评价（"整体进度总体可控、工作成效较好"）+ **遗留问题列举**（分项列明：机房配套、网络隔离、光缆链路、FOP 点位等）+ 风险后果（"如不及时整改闭环，将直接影响 XX，极易造成 XX 风险，威胁 XX 核心业务稳定运行"）
3. **提示事项**（一、二、三、四，每条 = 要求 + 方法 + 时限）：
   - 一、对照清单逐项排查，把问题底数摸清楚（附问题清单，逐馆建台账，明确责任科室/责任人/完成时限，X 月 X 日前书面反馈）
   - 二、紧盯节点加紧整改，把遗留问题改到位（按问题逐类给整改路径：光缆→布放熔接成端；隔离→新增专用交换机物理划分；点位→通断测试归属核查；供电→配齐 42U 机柜/8 位 10A PDU。原则：**整改一项、验收一项、销号一项**）
   - 三、统筹标准衔接（两套标准的差补/预留二次升级窗口，避免重复施工）
   - 四、压实责任强化督导（主要领导过问/分管督办；建督办台账，**周调度、月通报**；整改不力视情通报、影响保障严肃追责）
4. **收尾要求**：政治站位句 + 报送机制（如每周五 17 时前报进展、X 月 X 日前书面报送完成情况）
5. **联系人、附件清单、落款**（发文机构全称+日期）

## 关键写作经验

- 问题清单做附件（序号/单位/问题类型/现状/整改要求/完成时限），正文只讲原则不堆细节
- "一、二、三、四"每段小标题用**动宾+目的**句式（"对照清单逐项排查，把问题底数摸清楚"），比干巴巴动词有力度
- 时限必须具体（自查反馈日、整改销号日、周报送节点），督办函的效力在时限
- 风险后果句是全文最有分量的一句，要写到"影响核心业务"级别

## 例外与边界

- 提示函用于"督促但不处分"层级；更正式用督办函，更严厉用通报
- 对上级/平级单位措辞降档（请求型），对下级可加"严肃追责"
