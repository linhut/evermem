从秋千测试赛"网络及安全倒排计划表"提炼。测试赛保障用倒排计划（从赛日往前排任务）。

## 表格结构

列：序号 / 工作阶段 / 工作项 / 工作内容 / 开始日期 / 结束日期 / 工期(天) / 备注

## 编制方法

- 按**工作阶段**分组（如"一、网络及安全设备到货验收上架"），每阶段拆成多个工作项
- 每个工作项写清**做什么**（工作内容要具体可验收）：
  - 设备到货清点：核对设备清单、型号、数量
  - 外观检查与登记：检查损坏、记录序列号、建资产台账
  - 上架安装：机柜规划、导轨安装、设备上架、线缆标签绑定
- 开始/结束/工期三列保证时间可跟踪
- 备注写设备类型（交换机、路由器、防火墙、高性能流量分析探针等）

## 经验要点

- 倒排：以赛日为锚点往前排，保证每个阶段有明确截止
- 工作项粒度：能直接派活、能检查完成度（"核对清单+登记序列号+上架+标签"四步是标准动作）
- 设备类任务先建资产台账，赛后可审计
- 分组编号（一、二、三…）便于汇报进度

## 例外与边界

- 不同保障组（网络/安全/无线电）各自倒排，最后对齐合并
- 日期为示例，按实际测试赛时间重排
