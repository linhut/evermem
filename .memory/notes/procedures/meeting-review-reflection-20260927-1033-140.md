从第十三届全国民族运动会信息技术部专题部署会议复盘材料提炼（陈龙检讨发言 + 复盘会议通知）。适用：重要会议出错后的"复盘会通知"与"反思检讨发言材料"写作。

## 复盘会议通知（五要素 + 写明议程）

标题：机构名 + 关于召开 XX 专题会议的通知；正文开头一句点明"为什么开"（深刻复盘 XX 会议暴露的问题、严肃纪律、压实责任）。
1. 会议时间（精确到时分+星期）
2. 会议地点
3. 参会人员（**按组/角色分组列姓名**，需点名到人：负责人、各小组、专家、施工团队）
4. 会议内容/议程（当事人分别反思检讨 + 通报处理情况；领导总结讲话明确后续要求）
5. 有关要求（发言人员提前梳理问题与整改方向备书面材料；提前 10 分钟签到；团队负责人带队参会）
落款 + 联系人及电话。

## 反思检讨发言材料（经典四段结构）

开头：按会议安排，就 XX 工作中自身存在的问题作深刻反思检讨。
**问题归因**（第一句先定性：表面看是环节疏漏、根子是把关不严/落实不力；再列 3-4 个方面，每条 = 现象 + 根因 + 认识）：
1. 经验/梳理不足——具体失误实例（如漏发通知对象）+ 暴露的习惯短板
2. 协调不到位——只局部调试不彩排 → 现场卡顿（教训：必须全流程实战预演）
3. 督办检查不力——任务分派无跟踪，流于布置止于通知（"没有跟进就没有结果"）
4. 不够细心——归结共性，机关工作容不得马虎
**整改措施**（与问题一一对应、可量化）：
1. 参会单位清单制 + 通知双复核机制
2. 全会议流程彩排制度，重要会议至少两次完整预演、视频会议拉动各方设备联调
3. 督办台账：逐项登记、限时反馈、逐件销号（闭环管理）
4. 工作作风：多想一步、多查一遍、多问一声
结尾：以上是我的反思检讨，不当之处请各位领导批评指正。

## 复用要点

- 检讨材料的"问题"与"整改"必须一一对应，评委看的就是这条线
- 具体失误实例比空话有说服力（如"通过湘办通发送后未同时向高校正式通知"）
- 复盘会通知要把"谁检讨、谁来讲"写明，避免会务二次出错
