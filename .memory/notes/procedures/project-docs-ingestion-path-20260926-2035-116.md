F 盘项目文档（市应急指挥中心、政务云、省民宗委、省应急等约 1.2 万文档）的价值分层与处理路径。

价值分类：
- 方案类（融合通信 V4.2、建设方案、投标、政务云搬迁）→ 提炼成"方案怎么写"的 procedure 笔记，下次直接套结构。
- 流程类（巡检报告、考核表、交付资料、网络申请表）→ 提炼成流程清单，知道工作包含什么。
- 经验类（优化升级过程、搬迁、运维）→ 提炼成踩坑笔记。
- 记录类（周报、总结、感谢信）→ 只建索引，写总结时捞素材。

提炼原则：文档≠经验，全自动提炼质量不可控，只能选核心文档人工/AI 协作提炼，status 先 staged。不要追求覆盖 1.2 万文档，把核心的 20-50 份提炼好即可（信噪比优先）。

实测数据（市应急指挥中心）：1894 文档 → 9.67 MB 文本，8.5 分钟。全盘外推 60-100 MB。xlsx 表头启发式（第一个 ≥2 非空行的行作表头）有效；.doc 老格式 olefile 提取质量差，用 is_clean_text 拦截乱码；扫描件 PDF 无文本层需 OCR。

工具命令：
- list：C:/Python314/python.exe ingest.py list "F:/市应急指挥中心" --out files.json
- extract：C:/Python314/python.exe ingest.py extract "F:/市应急指挥中心" --out-dir "F:/知识库数据/chunks"
- 分块输出在 F:/知识库数据/chunks/<空间>/
