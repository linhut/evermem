从第十三届全国少数民族传统体育运动会信息技术部实际工作提炼（二次勘察总结 + 秋千测试赛运行手册）。

## 勘察机制（两轮制）

- 第一轮勘察（5月）摸底：梳理功能用房、网络基础设施、电力大屏、指挥中心、省市建设分工等短板
- 印发《场馆信息技术指南》指导两地整改
- 第二轮勘察（8月）对账：对照首轮问题清单评估整改成效，研判测试赛/正式赛技术保障风险
- 覆盖范围：全部竞赛场馆 + 分指挥中心 + 总指挥中心 + 集成实验室 + TOC
- 方法：现场踏勘 + 资料核对 + 技术对接

**关键：勘察不是看热闹，是对账。** 每轮要产出可对照的问题清单，下轮逐项核销。

## 勘察核查清单（7 项）

1. 机房建设与基础设施（配置完整性）
2. 网络设备（交换机、路由器在位与配置）
3. 光缆链路：纤芯资源是否够、光缆是否成端
4. 业务隔离：竞赛专网与赛事互联网是否**物理隔离**（交换机设备级）
5. 供电配套（UPS/市电）
6. 功能用房规划与落实
7. FOP 竞赛区域网络点位状态核验、机柜空间、PDU 资源

## 风险研判站位

- 勘察结论必须落到**时间节点风险**：按测试赛倒排时间，判断"按当前现状能否支撑测试赛"
- 进度滞后要直言：比如"无法满足测试赛保障条件、存在较大赛事运行风险"——不能含糊
- 区分技术问题与协同问题：统筹力度、权责边界、跨部门联动单独列节
- 标准差要指出：按省赛标准实施 vs 全国赛标准要求，存在二次升级

## 文档体系（筹委会信息技术部）

- 《场馆信息技术指南》—— 整改依据
- 勘察报告 —— 推进情况/问题/风险
- 督办类公文：工作提示函、督办函（本项目中"关于加快XXX建设进度的工作提示函"多版本迭代，含写实版与 skill 生成版对比）
- 运行手册 —— 见下

## 竞赛场馆信息技术运行手册编制框架

声明（保密）→ 修订记录 → 引言（编制目的、适用范围、编制依据）→ 概况（赛事概况、主办承办单位、时间地点、比赛项目）→ 各组职责与运行流程 → 保障要求。

依据文件：场馆信息技术指南 + 场馆运行图纸 + 测试赛竞赛日程与技术演练要求。手册随场馆实际持续修订（版本号如 V4.9→V4.61）。

## 例外与边界

- 赛事地名、单位名保留在原文，笔记只留方法论
- 手册对外保密、版权归筹委会，提炼时只取结构不取内容
- 其他大型活动（博览会、运动会）信息化保障可复用同一框架
