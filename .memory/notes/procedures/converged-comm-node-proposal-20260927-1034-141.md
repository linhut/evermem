从湘江新区融合通信系统项目建议书（v1.11→v1.14→V2.6 三版演进，中国电信编制）提炼。与笔记 118（平台能力模型）互补：118 讲平台能力与开放接口，本篇讲"节点建设项目建议书怎么编"。已入库笔记 118 覆盖 V4.2 升级方案，本篇覆盖项目建议书场景。

## 政策驱动（立项理由的硬依据）

《湖南省应急管理融合通信体系建设指导意见》：聚焦应急指挥音视频来源不一、制式各异、难以融合的突出问题，统一规范、整合优化；**2023年11月前各市州应急局完成市级节点建设，2024年11月前县市区应急局完成县级节点建设**——写必要性时引用这类带时限的省级文件最有说服力。

## 建议书章节结构

1. 项目简介（含建设背景）
2. 建设单位情况（**先亮现状家底**：已接入监控 X 路、云广播 X 台、对讲机 X 台、视频会议终端 X 个——实例：监控 10517 路、云广播 210 台、370/公私网对讲 56 台、横纵向视频会议终端 230+）
3. 项目建设必要性（政策 + 融合通信四大成效：提效率/快响应/保安全/助决策）
4. 需求分析（平台定位：依托指挥信息网，打通政务网/互联网，融合视频监控、现场图传、视频会议、语音、集群对讲）
5. 功能需求（五类融合调度：**视频/语音/数据/操作/会商**；数据融合含定位轨迹、生命体征手环；操作融合 = 一个座席一个界面一个人；会商融合支持短信唤起入会、微信入会）
6. 性能需求 / 安全需求（**GB/T 22239 等保三级**）/ 级联需求（上下级节点级联：授权、互联、数据查询、媒体互通、消息订阅；向上级联市级/省厅根节点，向下提供现场移动节点接入）
7. 业务支撑需求（**开放平台**：音视频融合/对讲/会议/消息群组/数据/终端路由/录播存储/设备管理统一对接，服务访问授权、次数限制、调用方 IP 限制、接口日志监控统计）
8. 管理需求：设备编码（统一注册登记唯一编码）/ 设备权限分级（上级可管下级）/ 设备状态监测（在线/离线/调度中）/ 数据管理（本地保存、级联被上级调取、授权访问控制）
9. 业务功能及流程（含业务流程图）

## 版本演进经验

- v1.11→v1.14→V2.6 三个版本逐轮补全：功能需求细化（数据融合/操作融合/会商融合逐步单列）、级联与开放平台需求后置加入——建议书迭代时优先补"接口与管控"类需求
- 建设单位现状数据要随每次修订更新（已接入资源数会变）

## 例外与边界

- 省级指导意见的节点时间节点是本地增量信息，各地政策不同需替换为当地文件
- 建设内容是运营商级（电信编制），政府侧写时技术细节可裁剪，保留需求与管控要求
