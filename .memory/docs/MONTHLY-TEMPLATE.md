# 恒忆月度回顾模板（每月 1 日执行）

> 依据 PLATFORM.md 4.6 五指标检视知识库健康度。数据命令见各节，填表后归档为 MONTHLY-YYYY-MM.md。

## 指标 1 · 库容与分布
- 命令：`mem.py stats`
- 记录：总数 ___ 条（procedure __ / lesson __ / fact __）；active __ / staged __ / suspect __
- 判断：语料增长趋势；类型是否失衡（procedure 过少=经验没沉淀为可复用配方）

## 指标 2 · 命中救火榜
- 数据源：recall 调用日志（**待建**：mem.py recall/search 需要输出命中 id，当前无日志）
- 现状替代：跑 `bench_search.py`，看 top1 平均分与预期命中率
- 判断：持续高分的笔记=核心资产（考虑标 hot）；持续下降=检索退化信号（触发 P2 向量或调阈值）

## 指标 3 · 候选转正率
- 命令：`mem.py candidates check`
- 记录：候选 __ 条（上限 50），超 30 天 __，超 60 天 __；本月转正 __ 条
- 判断：转正率 <30% → 收割规则过松或审核滞后；>60 天积压 → 批量归档（`mem.py candidates archive`）

## 指标 4 · 热层周转
- 命令：`mem.py hot --limit 20`（看 pinned 构成）；对照上月清单
- 记录：本月新进 __ 条，移出 __ 条；当前 fact __ / procedure __ / lesson __
- 判断：热层是否"有进有出"；若 20 条长期不动 → 审查是否应淘汰已内化条目（auto-fill 曾误选 4/6 元笔记，必须人工评审）

## 指标 5 · 无命中占比
- 数据源：recall 无命中次数（**待建**：检索日志）
- 现状替代：`bench_search.py` 无命中组数 + 平时对话中 recall 无命中的主观计数
- 判断：无命中偏高 → 提示补笔记或换查询词；连续无命中同一主题 → 该主题知识缺失，安排一次定点提取

## 行动项（每次回顾必做）
1. 候选批量审核：转正有价值的，归档超 60 天（Web「候选审核」页一键）。
2. 热层评审：人工确认 20 条仍全部"行动救命"；淘汰已内化项，提拔命中救火榜新宠。
3. 记录本月的：新增笔记数、新增领域、重大踩坑、检索基准数值（与上月对比）。
